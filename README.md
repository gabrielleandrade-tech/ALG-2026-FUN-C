# ALG-2026-FUN-C

ATIVIDADE DE FUNÇOES

Desenvolva um único programa em linguagem C, contendo todas as funções no mesmo código e utilizando apenas variáveis locais (não utilizar variáveis globais).

O programa deve conter:

Questão 1

Criar a função calcularHMS para receber um valor em segundos e converter para:

horas minutos segundos


Questão 2

Criar as funções:

isPar → retorna true se o número for par e false se for ímpar; isImpar → retorna true se o número for ímpar e false se for par.


Questão 3

Criar as funções:

media → calcula a média entre dois números; maior → retorna o maior valor entre dois números; menor → retorna o menor valor entre dois números.

O programa deverá ler 3 valores reais e mostrar:

maior valor; menor valor; média.
